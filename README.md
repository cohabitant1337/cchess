# ♟️ cchess (crazy chess)

Юмористическая тактическая версия шахмат для Android и браузера с динамически расширяемым полем, системой маны, древом навыков и нестандартными способностями, ломающими привычные правила игры. Полностью работает **офлайн**.
Создано с применением искусственного интеллекта.

---

## 🔥 Главные особенности и механики

* **Динамическая геометрия доски:** поле не ограничено сеткой 8×8 — оно растёт и меняет форму прямо во время партии с автоматическим масштабированием камеры.
* **Система маны и Древо навыков:** за каждый ход и взятие фигур начисляются мана и очки навыков (SP). Прокачивайте регенерацию маны, радиус хода фигур и открывайте ультимативные способности.
* **Нестандартные способности:**
  * **Мобилизация:** расширяет тыл игрока новым рядом клеток, сдвигает армию и призывает случайный отряд от 3 до 8 новых пешек.
  * **Барон Мюнхгаузен:** жертвует 3 пешки ради ракетного удара по области крестом `+`, превращая случайные клетки в непроходимые воронки на 10 ходов.
  * **Таран:** ладья проносится по прямой, снося до 3 фигур на своём пути ценой собственной жизни.
  * **Бункер:** прячет Короля под землю на 3 хода с последующим появлением в случайной безопасной клетке.
  * **Тарутинский маневр:** прорубает обходной коридор из 5 клеток («ручку кружки») за пределами краёв доски в выбранном направлении.
  * **Украсть ход:** случайное событие (шанс 10%), позволяющее перехватить инициативу в партии.
  * **Ультимейты древа навыков:** мини-игра в **«Крестики-нолики»** за право следующего хода и **«Шашечный прорыв»** для серийного взятия фигур перепрыгиванием.
* **Несколько режимов игры:**
  * Классика 1 на 1 (включая режим **«Друг напротив друга»** с переворотом доски на одном смартфоне).
  * **Dota-режим:** осада защитных Башен (Таверов) и вражеского Древнего.
  * **Королевская битва на 4 игроков:** расширенное поле `16×16`.

## 📲 Установка на Android (APK)

1. Перейдите в раздел **[Releases](../../releases)** справа на странице репозитория.
2. Скачайте актуальный файл **`.apk`** на смартфон.
3. Откройте файл и подтвердите установку (при необходимости разрешите установку приложений из неизвестных источников).
4. Игра полностью автономна и не требует подключения к интернету.

## 🛠️ Стек технологий и сборка

* **Ядро игры:** HTML5 Canvas, Vanilla JavaScript (ES6+), CSS3, Web Audio API (процедурная генерация звуков без внешних файлов).
* **Мобильная упаковка:** [Capacitor](https://capacitorjs.com) (Android).
* **CI/CD:** автоматическая сборка `.apk` настроена через GitHub Actions (`.github/workflows/build-apk.yml`).

### Локальный запуск веб-версии
```bash
# Клонировать репозиторий

# Запустить любой локальный сервер в папке www
```
